# 🔬 Smart Lab Inventory System

A web-based **Smart Lab Inventory Management System** built to efficiently manage laboratory equipment, components, and supplies.

## 🚀 Features

- 📦 Add, update, and delete lab inventory items
- 🔍 Search and filter items by category or component name
- 📊 Track stock levels and get low-stock alerts
- 🧪 Manage lab components with quantity and status tracking
- 👤 User-friendly and responsive interface
- 📁 Clean UI built with HTML, CSS, and Bootstrap

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| Python / Django | Backend framework |
| HTML, CSS, Bootstrap | Frontend UI |
| SQLite | Database |
| JavaScript | Interactive components |

## ⚙️ Installation & Setup

```bash
git clone https://github.com/shivanjalimulik/Smart-Lab-Inventory-System.git
cd Smart-Lab-Inventory-System
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open your browser at: `http://127.0.0.1:8000/`
